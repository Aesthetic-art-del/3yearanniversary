SANDRA & SREELESH - THE SERIES
==============================

HOW TO OPEN
Double-click index.html. Keep the "media" folder next to it. (Fonts need internet.)

HOW TO EDIT
Open index.html in Notepad or VS Code and find the block marked EDIT ME.
- M lists the photos and V lists the videos. Everything below points to them by name,
  like img:M.ledge or video:V.pout. Change the name to change the picture.
- To add a photo: put the file in media, add one line to M, then use it.

NEW THINGS YOU CAN EDIT (all in the CONFIG block, near the bottom)
- Audio: drop two files into media named  our-song.mp3  and  voice-note.mp3.
  They appear in the letter section automatically. Until the files exist, nothing shows.
- Timeline: every episode has date:'...'. Only Pilot, Third Onam and the Anniversary
  Special are certain. Check the others.
- recap: the 20-second "Previously on..." montage. ms = seconds each slide stays (in ms).
- (the "Who said it?" game was removed; the whoSaid list in the file is now unused)
- guess: the blurry-photo game. fx / fy choose where the zoom lands.
- memories: the scratch-card photos. pos chooses which part of the photo shows.
- openWhen: the sealed letters. Each has text plus an optional img or video.
- map: pins. Change lat / lng to move one. The lake trip is set to Alappuzha, so fix it if needed.
- postCredits: the hidden clip and line after the credits.
- nextDate: the "Your next date is booked for" ticket. Put a real date in when.
- wishlist: the Season 4 choices.
- nicknames: typing one anywhere (or in the search box) throws confetti. Add her pet names.
- heroEggs: the two secret tap spots on the home photo (her eyes, his sunglasses).
- Before sending it: type the real card number and PIN into giftCode and giftPin (never share them in chat).

SECRET: tap the red S&S logo 5 times to unlock the finale for testing.

GIFT VIDEO NOTE: the zip was too big to include the gift video. Copy your original video into media/ and name it anniversary-surprise-video.mp4 (the page already points to that name). The published link uses a near-original-quality copy.
